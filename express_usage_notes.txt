Express API - Usage Notes (Port 5100)
====================================

Start the server (live logs in terminal)
----------------------------------------
- Use 5100 regardless of .env:
  PORT=5100 node server.js

- Or set once in .env:
  PORT=5100
  HOST=0.0.0.0
  # Then run
  node server.js

Background (daemon-like) and logs
---------------------------------
- Start and tail logs with nohup:
  nohup PORT=5100 node server.js > server.log 2>&1 &
  tail -f server.log

- Stop later:
  pkill -f "node server.js"

- Scripts available:
  chmod +x scripts/start-daemon.sh scripts/stop-daemon.sh
  ./scripts/start-daemon.sh           # starts on 5100 by default (uses PORT if set)
  tail -f server.log                  # view logs
  ./scripts/stop-daemon.sh            # stops the background server

Health check
------------
  curl http://127.0.0.1:5100/health

Upload + translate (SRT or TXT)
-------------------------------
- Basic (defaults to English):
  curl -X POST http://127.0.0.1:5100/api/translate \
    -F "file=@/absolute/path/to/subtitle.srt"

- Specific language:
  curl -X POST http://127.0.0.1:5100/api/translate \
    -F "file=@/absolute/path/to/subtitle.srt" \
    -F "to=Spanish"

- Advanced options:
  curl -X POST http://127.0.0.1:5100/api/translate \
    -F "file=@/absolute/path/to/subtitle.srt" \
    -F "to=French" \
    -F "from=English" \
    -F "model=gpt-4o-mini" \
    -F "temperature=0.3" \
    -F "structuredMode=array" \
    -F "batchSizes=[10,100]" \
    -F "historyPromptLength=100" \
    -F "useModerator=false" \
    -F "prefixNumber=false" \
    -F "lineMatching=false" \
    -F "systemInstruction=Translate casual tone to formal Japanese"

Translate by server path
------------------------
- Basic:
  curl -X POST http://127.0.0.1:5100/api/translate-path \
    -H "Content-Type: application/json" \
    -d '{
      "inputPath": "/absolute/path/to/subtitle.srt",
      "to": "Spanish"
    }'

- With options:
  curl -X POST http://127.0.0.1:5100/api/translate-path \
    -H "Content-Type: application/json" \
    -d '{
      "inputPath": "/absolute/path/to/subtitle.srt",
      "outputPath": "/absolute/path/to/output.srt",
      "to": "French",
      "from": "English",
      "model": "gpt-4o-mini",
      "temperature": 0.3,
      "structuredMode": "array",
      "historyPromptLength": 100,
      "useModerator": false,
      "prefixNumber": false,
      "lineMatching": true,
      "systemInstruction": "Translate with a formal tone"
    }'

Download translated file
------------------------
- If you uploaded a file, the response contains outputFileName:
  curl -O "http://127.0.0.1:5100/api/download/<outputFileName>"

- Example (auto-extract file name and download):
  RESPONSE=$(curl -s -X POST http://127.0.0.1:5100/api/translate \
    -F "file=@/absolute/path/to/subtitle.srt" \
    -F "to=Spanish")
  FILENAME=$(echo "$RESPONSE" | jq -r '.outputFileName')
  curl -O "http://127.0.0.1:5100/api/download/$FILENAME"

Requirements
------------
- Set your OpenAI key in .env before translating:
  OPENAI_API_KEY=sk-...
- Required packages (install manually as needed):
  npm install express multer loglevel undici dotenv openai

Notes
-----
- structuredMode accepts only: array | object (anything else disables it)
- Booleans in multipart are strings; use 'false' to disable features
- Arrays in multipart are JSON strings (e.g., [10,100])
- Keep terminal open for live logs if not running with nohup


Ollama (local LLM) usage
------------------------
Run Ollama in Docker (OpenAI-compatible endpoint at :11434/v1):
```bash
docker run -d --name ollama -p 11434:11434 --gpus=all -v ollama:/root/.ollama ollama/ollama:latest
# optional: pre-pull a model, e.g., llama3.2:3b
docker exec -it ollama ollama pull llama3.2:3b
```

Translate using Ollama provider:
```bash
PORT=5100 LLM_PROVIDER=ollama OLLAMA_OPENAI_BASE_URL=http://127.0.0.1:11434/v1 node server.js

# multipart upload
curl -X POST http://127.0.0.1:5100/api/translate \
  -F "file=@test/data/test_ja_small.srt" \
  -F "to=English" \
  -F "model=llama3.2:3b" \
  -F "provider=ollama"

# async job
curl -s -X POST http://127.0.0.1:5100/api/translate-async \
  -F "file=@test/data/test_ja_small.srt" \
  -F "to=English" \
  -F "model=llama3.2:3b" \
  -F "provider=ollama" | tee job.json
```

Notes for Ollama:
- Moderation API is disabled automatically; useModerator is ignored.
- Structured output modes may be disabled depending on adapter support.
- Choose a chat-capable model (e.g., llama3.2:3b, qwen2.5, mistral) and set with `model=`.

Async translation jobs (recommended for long runs)
-------------------------------------------------
Enqueue an async translation job (returns jobId immediately):
  curl -s -X POST http://127.0.0.1:5100/api/translate-async \
    -F "file=@/absolute/path/to/subtitle.srt" \
    -F "to=English" \
    | tee job.json

Extract job id:
  JOB_ID=$(jq -r '.jobId' job.json)

Subscribe to live progress via SSE (Server-Sent Events):
  curl -N http://127.0.0.1:5100/api/jobs/$JOB_ID/events

Poll job status (alternative to SSE):
  curl http://127.0.0.1:5100/api/jobs/$JOB_ID

Download the result when finished:
  curl -O "http://127.0.0.1:5100/api/jobs/$JOB_ID/download"

Or using outputFileName from job status:
  FILENAME=$(curl -s http://127.0.0.1:5100/api/jobs/$JOB_ID | jq -r '.outputFileName')
  curl -O "http://127.0.0.1:5100/api/download/$FILENAME"

Minimal React frontend (no build tools)
--------------------------------------
Location:
  frontend-minimal/index.html

Usage:
  1) Start the API on port 5100
     PORT=5100 node server.js
  2) Open the HTML in a modern browser (double-click or serve statically)
  3) Set the Server URL if needed (defaults to http://127.0.0.1:5100)
  4) Choose an .srt/.txt file and click "Start Translation"
  5) Progress will update live via SSE and a download link appears when done

Notes:
  - CORS is enabled permissively for dev; lock it down in production.
  - Long jobs are processed in the background; you can close the SSE view and poll status later.
